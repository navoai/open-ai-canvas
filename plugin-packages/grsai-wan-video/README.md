# Grsai Wan Video

影策社区维护的 Grsai WAN 3.0 专属视频请求协议，非 Grsai 官方发行。安装本包后在渠道模型的请求协议选择 Grsai Wan Video，上游模型 ID 填 wan-3.0；Base URL 使用 https://grsaiapi.com 或 https://grsai.dakka.com.cn，在渠道凭据中配置 API Key。

后端从生成的 `grsai-wan-video.yingce-plugin` 包加载，不依赖系统内置 `host:` 适配器。

完整接口见 [docs/interface.md](docs/interface.md)。
